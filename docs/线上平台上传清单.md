# 极市线上平台上传清单

当前方案 B 会分别微调 SDK 使用的 FaceXFormer 和 SwinFace。训练阶段使用原始权重备份作为输入，将结果保存到训练产物目录；完成加载、推理和效果确认后，才决定是否替换 SDK 权重。因此训练前必须同时准备训练代码、SDK 源码和两个初始权重及其备份。

## 一、环境

平台环境与项目目标一致：

```text
Python 3.7
PyTorch 1.11
CUDA 11.3
数据集目录 /home/data/
```

## 二、上传目录

将本地 `project/` 下的 `train/` 和 `ev_sdk/` 上传到平台，不能形成额外的 `/project/project/` 层级。

训练代码至少应存在：

```text
/project/train/src_repo/dataset.py
/project/train/src_repo/finetune_facexformer.py
/project/train/src_repo/finetune_swinface.py
/project/train/src_repo/run.sh
```

FaceXFormer 和 SwinFace 的源码、权重必须存在：

```text
/project/ev_sdk/src/face_attr/models/facexformer/
/project/ev_sdk/src/face_attr/models/swinface/
/project/ev_sdk/model/facexformer/model.pt
/project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt
/project/ev_sdk/model/facexformer/model_original.pt
/project/ev_sdk/model/swinface/checkpoint_original.pt
```

`run.sh` 不会调用旧的 `train.py` 或 `model.py`。旧的 `best_model.pth` 也不是当前方案 B 的 SDK 权重。

权重不提交到 GitHub，但云平台训练前必须准备好两个当前 SDK 权重及其备份。微调脚本默认读取备份，不会覆盖 `/project/ev_sdk/model/` 下的原始文件。

## 三、发起训练

平台训练命令填写：

```bash
bash /project/train/src_repo/run.sh
```

模型保存路径可以填写：

```text
/project/train/models
```

数据集选择平台提供的 V5、V6、V7 或 V8，脚本统一从 `/home/data/` 读取，不硬编码版本号。

`run.sh` 会依次执行：

```bash
python /project/train/src_repo/finetune_facexformer.py \
  --data_dir /home/data \
  --epochs 5 \
  --batch_size 16 \
  --lr 1e-5 \
  --num_workers 4 \
  --device cuda \
  --checkpoint /project/ev_sdk/model/facexformer/model_original.pt \
  --output /project/train/models/facexformer_finetuned.pt

python /project/train/src_repo/finetune_swinface.py \
  --data_dir /home/data \
  --epochs 5 \
  --batch_size 32 \
  --lr 1e-5 \
  --num_workers 4 \
  --device cuda \
  --checkpoint /project/ev_sdk/model/swinface/checkpoint_original.pt \
  --output /project/train/models/swinface_finetuned.pt
```

训练成功时应分别看到：

```text
saved /project/train/models/facexformer_finetuned.pt
saved /project/train/models/swinface_finetuned.pt
```

两个 loss 都应为有限数字，不能出现 `nan` 或 `inf`。

## 四、建议的冒烟测试

正式训练前，可以在平台终端分别执行一次单 epoch 测试。当前脚本不支持 `--max_samples`，所以使用单 worker 检查数据路径、XML 解析、模型前向和权重保存。

```bash
cd /project/train/src_repo
python finetune_facexformer.py \
  --data_dir /home/data \
  --epochs 1 \
  --batch_size 4 \
  --num_workers 0 \
  --device cuda
```

通过后执行：

```bash
python finetune_swinface.py \
  --data_dir /home/data \
  --epochs 1 \
  --batch_size 4 \
  --num_workers 0 \
  --device cuda
```

两个冒烟测试都通过后，再执行正式的 `run.sh`。

## 五、训练后 SDK 测试

训练完成后，临时微调权重位于：

```text
/project/train/models/facexformer_finetuned.pt
/project/train/models/swinface_finetuned.pt
```

确认临时权重可以被 SDK 加载并完成推理后，再手动复制替换对应 SDK 权重。替换前保留 `model_original.pt` 和 `checkpoint_original.pt`，不要删除备份。

当前模型职责为：

- FaceXFormer：朝向、性别、种族；
- SwinFace：年龄、表情、眼镜、帽子、胡须；
- 年龄最终以 SwinFace 的连续回归结果为准；
- `emotion=-1` 不参与 SwinFace 表情损失。

SDK 测试至少应保留以下文件：

```text
/project/ev_sdk/src/ji.py
/project/ev_sdk/src/model_api.py
/project/ev_sdk/src/face_attr/
/project/ev_sdk/model/facexformer/model.pt
/project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt
```

平台终端可用以下命令检查目录：

```bash
find /project/train/src_repo -maxdepth 1 -type f | sort
find /project/ev_sdk/model /project/ev_sdk/src -type f | sort
```

不要上传 `__pycache__/`、`*.pyc`、`.git/` 和本地 `data/`。模型权重不提交到 GitHub，但必须保留在云平台的 SDK 目录中供训练和测试使用。
