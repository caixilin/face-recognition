# 极市线上平台上传清单

这份文档用于把本项目上传到线上训练平台。项目分为两个部分：

- **训练工程**：用于训练模型，上传到 `/project/train/`
- **模型榜 SDK**：用于模型测试，上传到 `/project/ev_sdk/`

如果当前只进行训练，先完成第一部分即可，不需要先上传 SDK。

---

## 一、训练工程上传

### 1. 本地文件与线上路径对应关系

| 本地文件 | 上传到线上 |
|---|---|
| `train/src_repo/dataset.py` | `/project/train/src_repo/dataset.py` |
| `train/src_repo/model.py` | `/project/train/src_repo/model.py` |
| `train/src_repo/train.py` | `/project/train/src_repo/train.py` |
| `train/src_repo/run.sh` | `/project/train/src_repo/run.sh` |

训练阶段实际需要上传的文件只有这 4 个：

```text
train/src_repo/
├── dataset.py
├── model.py
├── train.py
└── run.sh
```

### 2. 线上训练目录

根据你提供的线上平台截图，目前实际目录是：

```text
/project/train/
├── src_repo/
│   ├── __pycache__/       # 图片中存在，但不是运行必需文件
│   ├── dataset.py
│   ├── model.py
│   ├── train.py
│   └── run.sh
├── log/                   # 图片中为空
├── models/
│   ├── facexformer/
│   │   └── model.pt
│   ├── swinface/
│   │   └── checkpoint_step_79999_gpu_0.pt
│   └── README.md
└── result-graphs/
```

其中：

- `/project/train/src_repo/`：放训练代码。
- `/project/train/log/`：训练日志目录，截图中为空。
- `/project/train/models/`：截图中已经放有 FaceXFormer、SwinFace 权重和 `README.md`，训练结果也会写入这里。
- `/project/train/result-graphs/`：训练结果图目录，可以为空。

`run.sh` 会自动创建日志、模型和结果图目录。截图中的两个权重不是本次自定义训练的输出模型；正式训练后还应检查是否生成 `best_model.pth`。

### 3. 不要上传的文件

以下文件不是训练必须文件：

```text
__pycache__/
*.pyc
.git/
.gitignore
README.md
models/README.md
train/models/facexformer/model.pt
train/models/swinface/checkpoint_step_79999_gpu_0.pt
本地 data/
```

注意：截图中 `train/models/` 下的两个权重已经存在，但它们不是训练代码运行所必需的输入文件。是否保留由平台任务需求决定；不要把它们误认为训练成功后生成的 `best_model.pth`。

尤其不要把本地项目根目录整体直接上传到 `/project/train/`，否则容易形成错误的多层目录，例如：

```text
/project/train/train/src_repo/train.py
```

正确路径必须是：

```text
/project/train/src_repo/train.py
```

### 4. 发起训练时的填写方式

在平台“发起训练”页面填写：

```text
执行命令：
bash /project/train/src_repo/run.sh

模型保存路径：
/project/train/models
```

预加载模型先不要勾选。数据集选择平台提供的对应版本，例如：

训练数据由平台挂载到 `/home/data/`，不需要把本地数据上传到项目目录。

### 5. 训练开始后的正常现象

训练日志应当出现类似内容：

```text
使用设备: cuda
数据集目录: /home/data
训练样本数: ...，验证样本数: ...
Epoch [1/50] train_loss=... val_loss=...
```

`train_loss` 和 `val_loss` 必须是数字，不能是：

```text
nan
```

训练成功后，模型通常保存为：

```text
/project/train/models/best_model.pth
```

### 6. 快速冒烟测试

不建议每次排查都直接跑 50 个 epoch。当前 `train.py` 支持限制样本数和 DataLoader worker 数，可以先用少量样本测试路径、XML 解析、模型前向和保存流程。

平台终端中执行：

```bash
cd /project/train/src_repo
python train.py \
  --data_dir /home/data \
  --epochs 1 \
  --batch_size 4 \
  --max_samples 32 \
  --num_workers 0 \
  --device cuda
```

快速测试正常时应看到：

```text
使用设备: cuda
训练样本数: ...，验证样本数: ...
Epoch [1/1] train_loss=... val_loss=...
保存最优模型: /project/train/models/best_model.pth
训练完成！
```

确认测试通过后，再使用平台发起正式训练：

```bash
bash /project/train/src_repo/run.sh
```

## 二、模型榜 SDK 上传

模型榜测试与训练是两个独立工程。只有准备模型榜测试时，才需要上传这一部分。

### 1. 本地文件与线上路径对应关系

| 本地文件或目录 | 上传到线上 |
|---|---|
| `ev_sdk/src/ji.py` | `/project/ev_sdk/src/ji.py` |
| `ev_sdk/src/model_api.py` | `/project/ev_sdk/src/model_api.py` |
| `ev_sdk/src/face_attr/` | `/project/ev_sdk/src/face_attr/` |
| `models/facexformer/model.pt` | `/project/ev_sdk/model/facexformer/model.pt` |
| `models/swinface/checkpoint_step_79999_gpu_0.pt` | `/project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt` |

### 2. 线上 SDK 目录

```text
/project/ev_sdk/
├── src/
│   ├── ji.py
│   ├── model_api.py
│   └── face_attr/
│       ├── __init__.py
│       ├── analyzer.py
│       ├── detector.py
│       ├── main.py
│       └── models/
│           ├── facexformer/
│           └── swinface/
└── model/
    ├── facexformer/
    │   └── model.pt
    └── swinface/
        └── checkpoint_step_79999_gpu_0.pt
```

`face_attr` 必须是整个目录，不能只上传 `ji.py` 和 `model_api.py`。两个权重文件必须保留各自的文件夹层级。

正确路径：

```text
/project/ev_sdk/src/face_attr/analyzer.py
/project/ev_sdk/model/facexformer/model.pt
/project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt
```

错误路径示例：

```text
/project/ev_sdk/ev_sdk/src/ji.py
/project/ev_sdk/src/src/face_attr/analyzer.py
/project/ev_sdk/model/models/facexformer/model.pt
```

### 3. SDK 结构检查命令

上传后，在平台终端执行：

```bash
find /project/ev_sdk -maxdepth 6 -type f | sort
```

至少应当看到：

```text
/project/ev_sdk/src/ji.py
/project/ev_sdk/src/model_api.py
/project/ev_sdk/src/face_attr/analyzer.py
/project/ev_sdk/src/face_attr/models/facexformer/network/models/facexformer.py
/project/ev_sdk/src/face_attr/models/swinface/model.py
/project/ev_sdk/model/facexformer/model.pt
/project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt
```

## 三、训练目录检查命令

训练文件上传后执行：

```bash
find /project/train -maxdepth 3 -type f | sort
```

训练代码至少应当包含：

```text
/project/train/src_repo/dataset.py
/project/train/src_repo/model.py
/project/train/src_repo/run.sh
/project/train/src_repo/train.py
```

检查缓存和 Git 目录：

```bash
find /project/train /project/ev_sdk \
  \( -name '__pycache__' -o -name '.git' \) -print
```

如果有输出，说明上传了缓存或 Git 元数据。它们通常不是运行必需文件，可以在重新上传时排除。

---

## 四、重要说明

训练输出的：

```text
/project/train/models/best_model.pth
```

与模型榜 SDK 当前使用的：

```text
/project/ev_sdk/model/facexformer/model.pt
/project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt
```

不是同一个模型。当前 SDK 代码默认使用 FaceXFormer 和 SwinFace 两个预训练权重，并不会自动加载训练生成的 `best_model.pth`。

因此：

- 只训练：上传 `/project/train/src_repo/` 的 4 个文件。
- 做模型榜测试：再单独上传 `/project/ev_sdk/` 的源码和两个权重。
- 不要删除 `/project/train/models/` 中的平台训练输出，除非确认对应训练任务已经不再需要。
