# 项目重要变更记录

本文档记录会影响训练、SDK 推理或模型权重的关键修改。每次修改应注明日期、文件、原因、来源和验证方式。

## 2026-09-29

### 对照榜单规则修复 SDK 与训练脚本缺陷

- 来源：极市【人脸属性分析】赛道说明与打榜规则（`https://www.cvmart.net/topList/11022`）。已逐条核对属性取值范围、`toward` 三分类定义、ACC 判定规则、JSON 输出协议和评分权重（精度 80 / 性能 20，标准 fps 30）。

- 文件：`project/ev_sdk/src/face_attr/analyzer.py`
- 变更：SwinFace 的 `Smiling`、`Eyeglasses`、`Wearing Hat`、`Mustache`、`No Beard` 五个头输出维度是 2（`OutputModule.output_sizes` 已确认），原代码对 `(B, 2)` 张量直接调用 `.sigmoid().item()`，会抛出 `RuntimeError: a Tensor with 2 elements cannot be converted to Scalar`，导致 SDK 推理必然崩溃。新增 `_positive_class_probability()`，对 2 分类头取 softmax 正类概率，对单 logit 头退回 sigmoid。
- 变更：`_headpose_to_orientation()` 原来只返回 `front/left/right/up/down`，永远不可能返回 `back`，而 `model_api._toward_value()` 里的 `back` 分支因此是死代码。榜单 ACC 规则 2 规定 `toward=back` 识别正确即判对，这条链路失效会直接丢分。现改为按榜单定义输出 `front/back/other`：偏航角绝对值 ≥ 90° 判为 `back`，偏航与俯仰均 < 30° 判为 `front`，其余为 `other`。
- 变更：默认权重路径由 `models/` 改为 `model/`（SDK 权重目录是单数），否则 `main.py` 找不到权重。
- 变更：补充注释说明 `gender` 头的类别顺序依赖权重来源——原始预训练权重为 0=男、1=女，而 `finetune_facexformer.py` 直接使用榜单标签（0=女、1=男）训练，两者解码方式相反，替换权重时必须同步修改。

- 文件：`project/ev_sdk/src/model_api.py`
- 变更：`_build_analyzer()` 的源码候选路径由 `parents[2]/"src"`（即不存在的 `project/src`）改为 `parents[1]/"src"`（即 `ev_sdk/src`），权重回退路径同步改为 `model/`。
- 变更：新增 `_race_value()`。FaceXFormer 的 race 头是 5 类，而榜单只定义 0-3（黄/白/黑/印第安）与 -1，越界预测统一返回 `-1`，避免输出榜单未定义的 `4`。
- 变更：`toward=back` 时把全部属性重置为 `-1`，与榜单「不告警情形」示例一致；ACC 规则 2 下这些属性不参与判分。
- 变更：`head` 对象同时输出 `emotion` 和 `expression` 两个键。榜单字段表同时列出了这两个名称，而示例用的是 `expression`，两个都输出可避免判分脚本读不到表情。

- 文件：`project/ev_sdk/src/ji.py`
- 变更：`detector()` 原来不传 `target_id`，所有检测框都落到默认值 `"1"`，多张人脸时 id 重复，违反榜单「属于同一人的人员id是唯一的」。现按置信度降序为每个目标分配唯一 id，保证同一帧内 id 不重复且顺序稳定。

- 文件：`project/train/src_repo/finetune_swinface.py`
- 变更：`Eyeglasses`、`Wearing Hat`、`Mustache` 三个 2 分类头原来用 `binary_cross_entropy_with_logits(outputs[k].reshape(-1), target)`，输入被展平成 `(B*2,)` 而目标仍是 `(B,)`，实测抛出 `ValueError: Target size (torch.Size([2])) must be the same as input size (torch.Size([4]))`，训练无法启动。现改用 `masked_cross_entropy` 做 2 分类交叉熵；眼镜标签按榜单 0/1/2 语义把 1 和 2 都映射为正类。

- 文件：`project/train/src_repo/finetune_facexformer.py`
- 变更：补充注释，明确 `gender`/`race` 标签顺序与 `toward` 欧拉角目标必须与 SDK 解码保持一致，避免训练与推理的类别语义错位。

- 文件：`tests/test_sdk_interface.py`
- 变更：同步更新断言以匹配榜单规范（`expression` 键存在、`toward=back` 时属性为 `-1`）。

- 已核对但判定为正确、不做修改：`toward != "front"` 时跳过 SwinFace。榜单 ACC 规则 2、3 规定 `back`/`other` 识别正确即判对，属性不参与判分，跳过可同时省算力（性能占 20% 权重）。
- 验证：`pytest tests` 4 项全部通过；用桩模型替代真实权重跑通 `FaceAttributeRuntime.process()`，确认 `front/back/other` 三种朝向的输出、多目标 id 唯一、race 越界返回 `-1`；`masked_cross_entropy` 对 2 分类头返回有限损失且全缺失标签时返回 0。临时验证脚本已删除，`git status` 无残留文件。未在云端执行真实数据训练。

- 验证：两个 checkpoint 的字段和 `module.` 前缀已核对；原始备份可加载到两个训练模型；Python `py_compile`、Pylance 诊断、Shell 语法和路径检查通过；本地随机样本前向/反向传播通过（FaceXFormer batch size=1，SwinFace batch size=2）。SwinFace 使用 batch size=1 时会触发 BatchNorm 限制，因此线上冒烟测试不要使用 batch size=1；尚未在云端执行真实数据训练。

### FaceXFormer 年龄标签调查

- 文件：`project/train/src_repo/finetune_facexformer.py`
- 当前代码：年龄头输出 8 类，临时年龄边界为 `(0, 4, 13, 20, 30, 40, 50, 60, 101)`。
- 已确认：本地 FaceXFormer 实现的 `age_prediction_head` 输出维度是 8；模型结构本身没有保存年龄边界定义。
- 榜单规则：榜单年龄标签是 `0-100` 或 `-1`，但这只能说明标注输出范围，不能直接推出 FaceXFormer 的 8 个训练年龄桶。
- 当前决定：在查到 FaceXFormer 原始训练代码或官方标签定义前，不把临时边界视为最终方案，也不据此宣称训练结果正确。
- 待确认：FaceXFormer 原始数据集、年龄类别到年龄范围的映射，以及榜单连续年龄标签转换到 8 类年龄目标的规则。
- 代码风险：当前微调脚本中的年龄分桶属于待替换的临时实现；云端训练前必须完成来源核对。

### SwinFace 年龄输出核对

- 文件：`project/ev_sdk/src/face_attr/models/swinface/analysis/subnets.py`
- 结论：SwinFace 的 `Age` 输出头维度为 1，是连续数值回归，不使用年龄桶；模型输出没有 `argmax`。
- 训练：`project/train/src_repo/finetune_swinface.py` 使用有效年龄标签的均方误差损失；年龄为 `-1` 的样本不参与年龄损失。
- SDK：`project/ev_sdk/src/face_attr/analyzer.py` 原样读取 `Age` 回归值；`project/ev_sdk/src/model_api.py` 的 `_age_value()` 会四舍五入，并将结果限制到 `0-100`，空值返回 `-1`。
- 与榜单要求的关系：榜单年龄字段要求 `0-100` 或 `-1`，因此 SwinFace 的年龄输出链路与该格式一致，不需要年龄桶转换。
- 注意：模型本身不会根据训练标签是否为 `-1` 自动输出 `-1`；未知年龄只是在训练时忽略，推理时仍会对检测到的人脸给出回归值。

### 年龄模型职责确定

- 文件：`project/train/src_repo/finetune_facexformer.py`
- 决定：最终年龄以 SwinFace 的连续回归结果为准；FaceXFormer 不再训练年龄分支。
- 变更：移除 FaceXFormer 微调脚本中的临时 `AGE_BINS`、年龄分桶函数和年龄交叉熵损失，仅保留性别、种族和朝向训练。
- 原因：当前无法从 FaceXFormer 源码确认 8 个年龄类别的真实边界，而 SwinFace 的年龄输出与榜单 `0-100/-1` 格式一致。
- 验证：FaceXFormer 与 SwinFace 微调脚本均已通过本地 `py_compile`；未执行本地训练。
