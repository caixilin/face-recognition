# 人脸属性分析项目文档

基于 **Python + PyTorch** 的人脸属性分析项目，用于检测图像中的人脸并分析年龄、性别、表情、朝向等属性。项目按照**极市开发者平台**规范组织，可直接在极市平台进行模型开发、训练与测试。

---

## 1. 环境要求

| 组件 | 版本 |
|------|------|
| 操作系统 | Ubuntu 18.04 |
| CUDA | 11.3 |
| cuDNN | 8.2 |
| Miniconda | 3 |
| JupyterLab | 3.3 |
| Python | 3.7 |
| PyTorch | 1.11 (cu113) |

## 3. 环境安装

### 3.1 一键安装脚本

在 Ubuntu 18.04 上执行：

```bash
bash env/install_env.sh
```

脚本会自动完成以下步骤：

1. **安装 Miniconda3**（若未安装）
2. **创建 Python 3.7 环境** `face_attr`
3. **配置清华源**（极市平台推荐）
4. **安装 PyTorch 1.11 (cu113)**
5. **安装 JupyterLab 3.3**
6. **安装项目依赖**

### 3.2 手动安装（可选）

```bash
# 创建 conda 环境
conda create -n face_attr python=3.7 -y
conda activate face_attr

# 安装 PyTorch 1.11 + CUDA 11.3
pip install torch==1.11.0+cu113 torchvision==0.12.0+cu113 \
    -f https://download.pytorch.org/whl/torch_stable.html

# 安装 JupyterLab 3.3
pip install "jupyterlab==3.3.*"

# 安装项目依赖
pip install -r requirements.txt
```

### 3.3 启动 JupyterLab

```bash
conda activate face_attr
jupyter lab
```

## 4. 极市平台使用流程

### 4.1 模型开发（训练）

1. 将 `train/` 目录内容上传到极市平台 `/project/train/`。
2. 在平台发起训练，执行命令：

```bash
bash /project/train/src_repo/run.sh
```

训练脚本遵循平台规范：

- 模型保存到 `/project/train/models/`
- 日志保存到 `/project/train/log/log.txt`
- 训练结果图保存到 `/project/train/result-graphs/`
- 数据集使用绝对路径 `/home/data/`

### 4.2 模型测试

1. 将 `ev_sdk/` 目录内容上传到极市平台 `/project/ev_sdk/`。
2. 将 `src/face_attr/` 及其 `models/` 源码一并复制到 `/project/ev_sdk/src/face_attr/`。
3. 将 FaceXFormer、SwinFace 权重放到 `/project/ev_sdk/model/`：
    `facexformer/model.pt` 和 `swinface/checkpoint_step_79999_gpu_0.pt`。
4. 确认 `torch`、`torchvision`、`facenet-pytorch` 已安装，再发起模型榜测试。
5. 发起模型榜测试。平台先调用 `ji.py` 的 `init()`，再将 BGR 图片逐张传入 `process_image()`。
6. `process_image()` 必须返回 JSON 字符串，包含 `algorithm_data` 和 `model_data.objects`。

模型代码接入位置：

| 位置 | 职责 |
|------|------|
| `ev_sdk/src/ji.py` | 极市模型榜入口，只负责初始化和协议输出 |
| `ev_sdk/src/model_api.py::FaceXFormerAdapter` | FaceXFormer 加载、预处理、推理和标签映射 |
| `ev_sdk/src/model_api.py::SwinFaceAdapter` | SwinFace 加载、预处理、推理和标签映射 |
| `ev_sdk/src/model_api.py::FaceAttributeRuntime` | 人脸检测、裁剪、两个模型的结果融合 |
| `/project/ev_sdk/model/` | 平台挂载的模型权重，不存放在源码目录 |

当前赛题输出使用 `emotion` 字段：`0` 表示皱眉，`1` 表示笑，`2` 表示平静，`-1` 表示其它或无法判断。SwinFace 的原始表情标签会在适配器中转换为该字段。

## 6. 训练代码说明

### 6.1 模型结构（`train/src_repo/model.py`）

轻量级卷积网络，包含一个卷积骨干网络和九个属性分支：

| 分支 | 输出 | 说明 |
|------|------|------|
| `age` | 1 维回归 | 年龄预测 |
| `gender` | 2 分类 | 0 女、1 男 |
| `toward` | 3 分类 | front、back、other；数据集 A 必有，是属性评分的前置条件 |
| `emotion` | 3 分类 | 皱眉、笑、平静 |
| `glasses` | 3 分类 | 无眼镜、普通眼镜、墨镜 |
| `race` | 4 分类 | 黄、白、黑、印第安 |
| `mask`/`hat`/`whiskers` | 2 分类 | 否/是 |

### 6.2 数据集格式（`train/src_repo/dataset.py`）

已在极市环境确认，数据集使用 VOC XML 标注，当前实际目录是按数据集编号分组，图片和 XML 同目录配对：

```text
/home/data/
├── 2792/
│   ├── xxx.jpeg
│   └── xxx.xml
├── 2795/
├── 2796/
└── 2975/
    ├── gt/
    └── imagefile/
```

训练代码同时兼容 `train/val`、`images/labels` 子目录和递归扫描；没有 `train/val` 时，会自动按固定种子划分 80% 训练集与 20% 验证集。

已确认的 XML 属性结构为 `object/attributes/attribute/name` 与 `value`，例如 `age`、`gender`、`glasses`、`race`、`emotion`、`mask`、`hat`、`whiskers`；数据集 A 的头肩标注还应包含 `toward`。`toward` 的规则为：两只眼睛都能看到是 `front`，两只眼睛都看不到是 `back`，侧面等其它情况是 `other`。数据集 B 若没有 `toward`，训练时仅对该属性跳过损失。目标框位于 `object/bndbox`。

评分时先判断 `toward`：只有 `toward` 预测正确，当前目标的其它属性预测才会继续参与正确性判断；因此训练脚本会对有标签的 `toward` 损失加权。

### 6.3 训练参数（`train/src_repo/train.py`）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data_dir` | `/home/data` | 数据集目录 |
| `--epochs` | 50 | 训练轮数 |
| `--batch_size` | 32 | 批大小 |
| `--lr` | 1e-3 | 学习率 |
| `--input_size` | 112 | 输入图像尺寸 |
| `--device` | 自动 | cpu/cuda |
