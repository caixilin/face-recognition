# 人脸属性分析项目文档

本项目保留云平台训练工程和模型榜 SDK 工程。两者统一放在本地 `project/` 目录中，便于整体上传；平台端仍使用固定的 `/project/` 根目录。

## 1. 环境要求

| 组件 | 版本 |
|------|------|
| 操作系统 | Ubuntu 18.04 |
| CUDA | 11.3 |
| cuDNN | 8.2 |
| Miniconda | 3 |
| JupyterLab | 3.3 |
| Python | 3.7 |

## 2. 项目目录结构

本地目录与云平台目录的对应关系如下。上传时将 `project/train/` 的内容放到 `/project/train/`，将 `project/ev_sdk/` 的内容放到 `/project/ev_sdk/`，不要形成 `/project/project/`。

```text
人脸识别/
├── project/
│   ├── train/                # 模型开发，对应平台 /project/train/
│   │   ├── src_repo/         # 训练代码
│   │   ├── models/           # 预训练权重和训练输出
│   │   ├── log/              # 训练日志
│   │   └── result-graphs/    # 训练结果图
│   └── ev_sdk/               # 模型榜 SDK，对应平台 /project/ev_sdk/
│       ├── model/            # FaceXFormer 和 SwinFace 权重
│       └── src/              # SDK 入口和模型适配代码
├── env/                      # 环境安装脚本
├── data/                     # 本地数据，不上传
├── docs/                     # 项目文档
├── pyproject.toml
└── requirements.txt
```

## 3. 环境安装

在 Ubuntu 18.04 上执行：

```bash
bash env/install_env.sh
```

脚本会创建 Python 3.7 环境 `face_attr`，安装 PyTorch 1.11 (cu113)、JupyterLab 3.3 和项目依赖。

## 4. 极市平台使用流程

### 4.1 模型训练

将本地 `project/train/` 内容上传到平台 `/project/train/`，然后执行：

```bash
bash /project/train/src_repo/run.sh
```

训练脚本使用以下平台路径：

- 数据集：`/home/data/`
- 模型输出：`/project/train/models/`
- 日志：`/project/train/log/`
- 结果图：`/project/train/result-graphs/`

### 4.2 模型榜 SDK 测试

将本地 `project/ev_sdk/` 内容上传到平台 `/project/ev_sdk/`。SDK 所需源码已经位于 `project/ev_sdk/src/`，两个权重位于 `project/ev_sdk/model/`，均需保留目录层级：

```text
project/ev_sdk/model/facexformer/model.pt
project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt
```

平台端对应路径为：

```text
/project/ev_sdk/model/facexformer/model.pt
/project/ev_sdk/model/swinface/checkpoint_step_79999_gpu_0.pt
```

平台会调用 `src/ji.py` 的 `init()` 和 `process_image()`。后者必须返回包含 `algorithm_data` 和 `model_data.objects` 的 JSON 字符串。

## 5. 训练代码说明

训练入口为 `project/train/src_repo/train.py`，训练模型定义在 `project/train/src_repo/model.py`，数据集加载逻辑在 `project/train/src_repo/dataset.py`。数据集使用 VOC XML 标注，平台数据目录为 `/home/data/`；没有预先划分的 `train/val` 目录时，代码会按固定种子划分训练集和验证集。

训练参数示例：

```bash
cd /project/train/src_repo
python train.py \
  --data_dir /home/data \
  --epochs 1 \
  --batch_size 4 \
  --max_samples 32 \
  --num_workers 0 \
  --device cuda
```

## 6. 重要说明

训练输出的 `/project/train/models/best_model.pth` 与 SDK 使用的 FaceXFormer、SwinFace 预训练权重不是同一个模型。训练工程和 SDK 工程可以分别上传，也可以从本地 `project/` 目录中统一取用。
