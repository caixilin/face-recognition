# 人脸属性分析项目文档

基于 **Python + PyTorch** 的人脸属性分析项目，用于检测图像中的人脸并分析年龄、性别、表情、朝向等属性。项目按照**极市开发者平台**规范组织，可直接在极市平台进行模型开发、训练与测试。

---

## 1. 环境要求

| 组件 | 版本 |
|------|------|
| 操作系统 | Ubuntu 18.04 |
| CUDA | 11.3 |
| cuDNN | 8.2 |
| Miniconda | 3 |
| JupyterLab | 3.3 |
| Python | 3.7 |
| PyTorch | 1.11 (cu113) |

项目遵循极市平台规范，`train/` 对应平台 `/project/train/`，`ev_sdk/` 对应平台 `/project/ev_sdk/`。

```text
│   │   ├── model.py          # 模型定义
│   │   ├── dataset.py        # 数据集加载
│   │   └── run.sh            # 训练命令脚本
│   ├── models/               # 模型保存（对应 /project/train/models/）
│   ├── log/                  # 日志保存（对应 /project/train/log/）
│   └── result-graphs/        # 训练结果图（对应 /project/train/result-graphs/）
├── ev_sdk/                   # 算法开发（对应 /project/ev_sdk/）
│   └── src/
│       └── ji.py             # 自动测试脚本
├── src/face_attr/            # 本地核心源码
│   ├── detector.py           # 人脸检测（MTCNN）
│   ├── analyzer.py           # 属性分析
│   └── main.py               # 主入口
├── tests/                    # 单元测试
├── models/                   # 本地模型权重（不入库）
├── data/                     # 本地数据（不入库）
├── docs/                     # 文档
├── pyproject.toml            # 项目配置
└── requirements.txt          # 依赖
```

## 3. 环境安装

### 3.1 一键安装脚本

在 Ubuntu 18.04 上执行：

```bash
bash env/install_env.sh
```

脚本会自动完成以下步骤：

1. **安装 Miniconda3**（若未安装）
2. **创建 Python 3.7 环境** `face_attr`
3. **配置清华源**（极市平台推荐）
4. **安装 PyTorch 1.11 (cu113)**
5. **安装 JupyterLab 3.3**
6. **安装项目依赖**

### 3.2 手动安装（可选）

```bash
# 创建 conda 环境
conda create -n face_attr python=3.7 -y
conda activate face_attr

# 安装 PyTorch 1.11 + CUDA 11.3
pip install torch==1.11.0+cu113 torchvision==0.12.0+cu113 \
    -f https://download.pytorch.org/whl/torch_stable.html

# 安装 JupyterLab 3.3
pip install "jupyterlab==3.3.*"

# 安装项目依赖
pip install -r requirements.txt
```

### 3.3 启动 JupyterLab

```bash
conda activate face_attr
jupyter lab
```

## 4. 极市平台使用流程

### 4.1 模型开发（训练）

1. 将 `train/` 目录内容上传到极市平台 `/project/train/`。
2. 在平台发起训练，执行命令：

```bash
bash /project/train/src_repo/run.sh
```

训练脚本遵循平台规范：

- 模型保存到 `/project/train/models/`
- 日志保存到 `/project/train/log/log.txt`
- 训练结果图保存到 `/project/train/result-graphs/`
- 数据集使用绝对路径 `/home/data/`

### 4.2 模型测试

1. 将 `ev_sdk/src/ji.py` 放到 `/project/ev_sdk/src/`。
2. 发起模型测试，选择挂载模型。
3. 确保 `ji.py` 中模型加载路径与所选模型路径一致（`/project/ev_sdk/model/`）。

## 6. 训练代码说明

### 6.1 模型结构（`train/src_repo/model.py`）

轻量级卷积网络，包含一个卷积骨干网络和四个属性分支：

| 分支 | 输出 | 说明 |
|------|------|------|
| `age` | 1 维回归 | 年龄预测 |
| `gender` | 2 分类 | 性别（male/female） |
| `expression` | 7 分类 | 表情 |
| `orientation` | 5 分类 | 朝向 |

### 6.2 数据集格式（`train/src_repo/dataset.py`）

数据集目录结构：

```text
/home/data/
├── train/
│   ├── images/xxx.jpg
│   └── labels/xxx.txt   # 每行: age gender expression orientation
└── val/
    ├── images/xxx.jpg
    └── labels/xxx.txt
```

标签文件格式（空格分隔）：

```text
25 0 0 0
```

对应：`age=25, gender=0(male), expression=0(neutral), orientation=0(front)`

### 6.3 训练参数（`train/src_repo/train.py`）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data_dir` | `/home/data` | 数据集目录 |
| `--epochs` | 50 | 训练轮数 |
| `--batch_size` | 32 | 批大小 |
| `--lr` | 1e-3 | 学习率 |
| `--input_size` | 112 | 输入图像尺寸 |
| `--device` | 自动 | cpu/cuda |
