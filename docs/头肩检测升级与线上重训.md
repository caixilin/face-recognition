# 头肩检测与赛道属性升级

**2026-10-04 本次训练安排**：用户确认使用 `bash /project/train/src_repo/run.sh` 完整训练头肩检测器、FaceXFormer、SwinFace 三套模型。头肩 `max_images=0`，默认 5 轮，优先加载已有 `/project/ev_sdk/model/headshoulder/model.pt` 继续微调；两个属性模型各 5 轮，仍分别保留 100,000 个目标上限。三套模型在开始训练前检查数据及权重，头肩与 SwinFace 保留逐轮快照。数据挂载、上传清单和完整操作见 [线上平台上传清单](线上平台上传清单.md) 第一节。下文原 3 轮/5,000 张命令是此前的小规模方案。

新版 SDK 已改为直接检测 `person` 和 `head`（头肩），并使用平台标签训练眼镜、口罩与朝向。改动不会改变旧 `.pt` 文件的内容，必须重新训练后再发起新版 SDK 测试。

## 1. 本次修改

| 项目 | 新实现 |
| --- | --- |
| head 框 | `head_detector.py` 加载按数据 A 原图 VOC 框训练的检测器，输出原图坐标下的头肩框；不再输出 MTCNN 人脸框或按比例放大。 |
| person 框 | 来自同一检测器的独立 person 类，不再由 head 框推算。只有 head 而没有匹配 person 时，不虚构 person 框；只有 person 的检测也保留。 |
| 眼镜 | SwinFace 眼镜头扩展为 3 类，训练保留 0 无眼镜、1 普通眼镜、2 墨镜。加载旧权重后保留原有两类参数，为第三类新增参数。 |
| 口罩 | SwinFace 增加 Mask 二分类头，使用 mask 0/1 标注监督，并输出识别结果。 |
| 朝向 | FaceXFormer 增加可训练的三分类头，使用 front/back/other 标注直接做分类损失，替代给标签人为分配角度的训练。旧权重基准仍按旧角度方式解码。 |
| 输出兼容 | 保留此前线上通过的 JSON 字段、年龄字符串、expression 兼容字段和告警逻辑；本次不改已验证的输出协议。 |
| 验证 | 保留三分类、各类统计与训练前基准。属性数据继续使用原目标级划分；新增检测数据按原图划分。 |

新头肩权重未挂载时，SDK 保留原 MTCNN 检测流程并打印所用检测类型；此时仍是人脸框，不能据此认为已经切换成头肩检测。挂载 `headshoulder_finetuned.pt` 后自动切换。旧属性权重仍能加载，新属性分支只有用新版脚本重训后才存在。

检测器采用 Torchvision 的 MobileNetV3 + Faster R-CNN，初始化可使用官方 COCO 权重，最终 head 类仍需平台数据监督。输入短边默认 640、长边上限 1280，用于保留场景中较小的头肩目标。没有承诺达到 30 FPS，需要在平台实测。[Torchvision 0.12 接口说明](https://docs.pytorch.org/vision/0.12/generated/torchvision.models.detection.fasterrcnn_mobilenet_v3_large_320_fpn.html)

## 4. 平台运行

要先只替换检测器、继续使用之前已验证的属性权重，可单独运行：

```bash
python /project/train/src_repo/train_head_detector.py \
  --data_dir /home/data \
  --epochs 3 \
  --max_images 5000 \
  --output /project/train/models/headshoulder_finetuned.pt
```

该命令不重新训练或覆盖两套属性模型。测试时选择新的头肩权重及原先的属性权重；SDK 支持这种组合。三分类眼镜、口罩和新朝向能力则需分别重新训练属性模型。

联网可下载检测初始化权重时，训练执行命令填写：

```bash
bash /project/train/src_repo/run.sh
```

已经上传离线初始化权重时：

```bash
COCO_CHECKPOINT=/project/ev_sdk/model/headshoulder/coco_mobilenet.pth \
  bash /project/train/src_repo/run.sh
```

入口依次训练头肩检测器、FaceXFormer、SwinFace。当前默认检测 5 轮、全量符合条件原图、batch 2；属性模型各 5 轮、最多 100,000 个目标。不能沿用旧耗时估计保证 12 小时完成；按线上耗时调整 `DETECTOR_*`、`EPOCHS`、`MAX_SAMPLES`。

每轮结束保存权重。全部训练结束后应有：

```text
/project/train/models/headshoulder_finetuned.pt
/project/train/models/facexformer_finetuned.pt
/project/train/models/swinface_finetuned.pt
```

同时会生成三份 `*.pt.validation.json`。文件名与旧属性产物相同，要保留旧产物先下载备份；模型测试时确认选择的是本次新训练任务的三个文件。

## 5. 先在线上核对头肩框

在能够访问新训练产物的环境执行：

```bash
python /project/ev_sdk/src/check_detection_boxes.py \
  --data-dir /home/data \
  --checkpoint /project/train/models/headshoulder_finetuned.pt \
  --max-images 12 \
  --output-dir /project/train/result-graphs/headshoulder_check
```

绿框是标注 head，红框是新检测器 head。下载该目录的对照图和 summary.json，检查红框是否覆盖头肩，以及 front/back/other 是否都有预测。候选 IoU 统计是诊断，仍不是官方总分。

对照旧 MTCNN 时可加 `--detector mtcnn`，并使用另一个输出目录；这个模式仍需 facenet-pytorch。对照脚本默认 auto，与 SDK 一样优先使用头肩权重，未找到时保留原 MTCNN。要确保这次检查的是头肩框，使用上述明确指定新权重的命令，或加 `--detector headshoulder` 强制要求头肩权重存在。
